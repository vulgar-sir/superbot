# superbot × Grok Bot UI 对照清单

> 对照对象：本机 Grok Bot `0.79.2`（Electron 42 / Chromium 148），2026-11-12 通过 CDP 实测计算样式与截图。
> 结论：**除品牌图标、字体、官方头像素材外，UI 组件、菜单项、尺寸与交互表面已逐项对齐**。superbot 不复制 Grok 的品牌资源，改用自有 Logo、Inter/系统字体和通用「色块 + 眼睛」吉祥物。

## 4. 交互与持久化

- **右键**：Bot、群聊、分组、侧栏空白、消息、资料库、动态。
- **拖拽**：Bot/群聊行排序与跨分组、分组排序、详情面板调宽。
- **@ 提及**：群聊输入 `@` 自动补全，↑↓/Enter/Tab/Esc。
- **消息**：右键菜单宽 224px，首行 5 个快捷表情（👍👎❤️😂🎉）+ 更多表情；回复/复制/复制请求 ID；回复条为单行灰色预览；滚动离开底部后新消息显示黑色「N 条新消息」胶囊（可忽略或跳转）。Grok 不展示思考过程与工具卡，superbot 也已隐藏。
- **最后一轮视觉收敛**：移除侧栏行内“…”按钮（右键仍是入口）；Bot/群聊菜单分隔线按 Grok 位置重排；账户菜单分隔线与“支持”文案对齐；搜索面板去掉 esc 徽标；新建 Bot 540px/120px 预览、输入框 40px 无蓝色焦点环；分组菜单改为 ArrowUp/ArrowDown；+ 菜单任务图标改为靶心；搜索结果字号 15/13；Provider 页去掉重复标题并改为整行模型卡；扩展页连接器改为 64px 两列行；团队/例程页字号放大。
- **服务端持久化**：表情回应、标为未读、隐藏/显示、回复关系、附件上传/展示、Bot 模板分享链接、权限规则；重载后保持。
- **工具审批**：自动审核开启时，权限规则匹配的工具会在 Worker 内创建审批记录并暂停；UI 弹出「允许一次 / 始终允许 / 拒绝」，批准后继续执行，拒绝后模型收到拒绝结果并继续对话。
- **快捷键**：`⌘/Ctrl+K` 搜索、`⌘/Ctrl+,` 设置、`⌘/Ctrl+反斜杠` 详情、`⌘/Ctrl+B` 侧栏、`/` 聚焦输入、`Esc` 关闭。
- **弹窗**：统一 16px 圆角、`scale(0.965)→1` 入场、半透明遮罩、Esc 关闭、焦点落在输入框。
- **设置**：应用内弹窗、左侧导航分页渲染（一次只显示一个设置分区）、无固定头部边框、右上浮动关闭、内容标题同步、主题/强调色。

## 5. UI 对照结论

客户端 UI 表面已逐项对齐并完成生产验收：侧栏、主聊天、详情面板、全部菜单、设置、连接应用、电脑、语音、登录、例程、附件、权限审批。品牌素材按用户要求使用 superbot 自有 Logo、Inter/系统字体与通用吉祥物。登录页按实测授权页的 500px 布局重做；连接应用提供统一连接入口；图片附件作为 image part 传给支持视觉的模型。

## 6. 验收方式

- `npx tsc --noEmit`、`npm run build`、`go test ./...` 通过。
- 迁移 0017–0021（隐藏/未读/反应/回复/附件/分享/权限审批）在生产执行成功，API 健康检查通过。
- 生产 `https://superbot.example.com/`（示例地址）逐项截图，无 console error。
